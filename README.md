# Bangers and Smash!

**Bangers and Smash!** is a free browser-based car racing game by Gunpowder Studios.

Play it here: https://gunpowderstudios.github.io/car-racer/

Race, jump, crash and compete in single-player or multiplayer, with destruction derby gameplay and a built-in track editor. It runs directly in a modern browser with no login and no installation required.

The game takes inspiration from classic driving games such as *Driver* and *Stunt Car Racer*, while being its own original project.

## Features

- Free to play in the browser
- Multiplayer racing
- Single-player racing and destruction derby
- Car damage, crashes, jumps, barrels and track hazards
- Built-in track editor
- Custom tracks can be used in multiplayer
- Keyboard, gamepad and touch controls
- Public source code for learning and experimentation

## For developers and learners

The project is written as a browser game using JavaScript, Three.js and WebGL. The source is public so people can inspect how the game works, learn from it and experiment with their own changes.

A formal licence file is not currently included in the repository, so redistribution or publishing modified versions should wait until licence terms are added.
